# Day 2 — Software Testing Fundamentals

## Overview

Day 2 focuses on the core concepts of Software Testing. These topics form the theoretical foundation required before moving into Manual Testing practices and Automation Testing.

By the end of this day, you should understand how software testing is performed, how defects are managed, and how testing activities are planned within real software development projects.

---

## Learning Objectives

After completing Day 2, you should be able to:

- Explain the purpose of Software Testing.
- Differentiate between Verification and Validation.
- Describe the Software Testing Life Cycle (STLC).
- Explain the Defect (Bug) Life Cycle.
- Differentiate between Severity and Priority.
- Write professional Bug Reports.
- Understand the purpose of a Test Plan.
- Understand the purpose of a Test Strategy.
