# Day 01 – QA Fundamentals

## Overview

This folder contains the documentation, revision material, and learning outcomes for **Day 01** of the **QA Automation Career Accelerator Bootcamp**.

Day 01 focuses on building the fundamental knowledge required for a Junior QA Engineer before moving into advanced topics such as Agile, SQL, API Testing, and Playwright Automation.

---

## Learning Objectives

By completing Day 01, the learner is able to:

- Understand Software and Hardware fundamentals.
- Explain the Input → Processing → Output (IPO) model.
- Describe the Software Development process.
- Identify the roles and responsibilities of a Software Development Team.
- Explain the Software Development Life Cycle (SDLC).
- Understand the Requirement Gathering process.
- Differentiate between Functional and Non-Functional Requirements.
- Apply Positive and Negative Testing techniques.
- Use Boundary Value Analysis (BVA) to design effective test cases.
- Understand common Password Validation rules and testing approaches.
